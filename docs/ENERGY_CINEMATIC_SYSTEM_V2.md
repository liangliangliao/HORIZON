## 2. 不可违反的产品原则

- 规则先结算，表现层只读取不可变的真实事件快照：eventId、规则版本、事件类型、实际资源 before/after/delta、实际星尘、真实父节点、来源日/兑现日、结果类别。演出档位不是奖励倍数；无真实倍率不显示 ×N；无真实资源增长不显示正向滚动或奖励喷发。
- 当日收益当日明确展示；未来回声在真实抵达日兑现，投放仅展示已安排的未来效果，不能把预测或预演视为已获收益。不得延迟业务入账来制造悬念。
- 播放、暂停、跳过、重播、回档、后台恢复不允许改变资源、概率、日期、历史、因果关系或重复发奖。用既有一次性结算机制，不新增第二套经济逻辑。
- 失败、负面回声、锁定、过期、模拟使用明确且不同的视觉语义；不制造近失中奖或虚构节点，不用庆祝动画掩盖负资源变化。
- 不增加付费继续、抽奖、随机加倍、连续签到压力或强制等待；动画可跳过，真实成果收据始终可见。普通行动轻量化，较长演出只用于有意义且真实的结果。

## 3. 通用 12 阶段演出与默认 Major 时间轴

以下是待调试建议参数，不是原视频实测值。以一次 Major 主释放 3.0s 为例；字幕的实际停留和额外因果节点可以延长表现总时长，不能截短旧规范的阅读窗口。低档压缩或省略阶段，高档可增加真实二次揭晓。

| 阶段 | 时间(s) | 主视觉 / 实现要求 |
| --- | --- | --- |
| 1 微光诞生 | 0–0.35 | 主体轮廓可辨；暗背景，小面积发光点，建立可理解的目标 |
| 2 主体颤动 | 0.35–0.9 | 位置、旋转、缩放或亮度脉动中的合适组合；局部而非全 UI 震动 |
| 3 持续蓄力 | 0.9–1.8 | 向心流与边缘扫光；持续生成寿命不同的细射线、光点；旧元素消亡新元素诞生 |
| 4 波动增强 | 1.8–2.65 | 包络总体上升，局部强弱交替；扩大覆盖、增加光束速度/长度/密度，主体仍可辨 |
| 5 临界状态 | 2.65–3.0 | 聚焦、姿势收紧；短暂停顿/收声可选，主体颤抖可止；不必所有事件完全冻结 |
| 6 瞬时白光 | 3.0–3.12 | 一次柔边局部高亮脉冲，保留轮廓，避免全屏高对比闪烁；减弱模式禁用 |
| 7 火焰状爆发 | 3.04–3.48 | 独立不规则能量体；白光下降时金橙或事件主题色开始显形，不是放大同一个光圈 |
| 8 能量扩散 | 3.12–4.1 | 外向冲击环、扇形光束、火星、拖尾；径向速度先快后慢，余光有寿命 |
| 9 成果显现 | 3.3–3.8 | 电芯、透镜、工具、真实节点等语义主体出现/被照亮；不遮住收据 |
| 10 数值增长 | 3.65–4.9 | 从真实 before 到 after 或 0 到真实 delta；与能量扩散部分重合；正负数明确 |
| 11 成果汇聚 | 4.9–5.7 | 真实资源落点、余额、链条/多源收束；有后续真实事件才再启动蓄力 |
| 12 余辉收尾 | 5.7–6.2+ | 衰减、镜头回位、保留可读最终收据，恢复输入；用户可直接跳至结果 |

以上核心时间轴约6.2s，仅作调参起点。旧规范中重大结果完整文字停留至少 clamp(1.15 + 字数 × 0.085, 2.2, 6) 秒，倍率独占至少2.4秒、结算至少3.4秒；新时间轴不得压缩这些窗口，文字与技术 cue 分轨。初始光弱、中间有小脉冲、主释放最突出；若后续存在第二真实成果则再次降强度再蓄势。主峰不是持续闪白。高对比闪光最多单次，默认用局部柔光和柔边；禁止频繁或大面积红/白闪烁，减弱动效默认可访问。

## 4. 渲染与运动技术要求

复用已有 RewardPlan.Cues、RewardDirector、CinematicEnergy、HorizonImmersion.shader、现有 CASCADE 导演和统一导演时钟。以下模块名称为建议职责，不是已存在的类；先查源码后决定扩展位置，避免平行重复系统。

- EnergyEnvelope：单时钟解析蓄势包络、相位、pulse、burst、afterglow。可用 E(t)=clamp(B(t)+A(t)*sin(phase(t)),0,1)，B 总体增、A 有界，频率/幅度分别可调，脉冲不可造成频繁全屏闪烁。采用确定性种子；暂停冻结所有层，包括材质参数与数值动画。
- SubjectMotion：局部可控噪声/阻尼弹簧、旋转、缩放、发力姿态。初始调参（相对于主体宽度）位置幅度0.2–1.2%，角度0.5–3度，缩放1.00–1.12；仅参考值，不应统一强制。主体本身与附着光源同一变换，UI不抖。减弱动效关闭抖动、推拉。
- LightField：独立核心 HDR 亮度、内层光晕、主体边缘 Fresnel/扫光、细针射线、宽扇光束、方向性拖尾、远层环境光。光束生命周期独立，采用透明渐变纹理和可调长度/角度/宽度；主体后方宽束与前景细粒分层。保留深色区和轮廓，不用一张规则放射图全程放大。URP HDR + Bloom（实际移动端 profile 验证），不能仅加 Bloom 强度替代素材。
- BurstField：至少分开白光脉冲、非圆形体积能量团、扩散环/扇束、火星和烟雾/余辉。原创透明爆炸 flipbook 或噪声扭曲的 shader/mesh，颜色中心近白、边缘金橙/主题色；不规则轮廓、局部涡动和高频细节，随时间膨胀并破碎。初始单次火团可见约0.3–0.9秒、外向余波0.5–1.5秒；先做高质量实际材质/纹理再调粒子。省电使用 atlas/低分辨率特效，无昂贵全屏 distortion。
- ParticleEmitters：向心光点、射线、外向火星、装饰星尘、真实星尘分别处理。发射速率、方向、速度、生命周期、旋转、尺寸有独立曲线。初期低速、临界前更新增强、释放 burst、余辉自然消失；池化、预热、硬预算，不逐帧 Instantiate/Destroy。装饰与真实奖励飞行必须可区分。
- SpatialComposition：背景/环境光/主体后方射线/实体/近场光核/冲击与火星/前景粒子/文字与收据。真实相机透视与遮挡，竖屏重新构图，主体居中但保留轮廓空区。普通 UI 隔离复用现有 CinematicCaption 机制，保证后创建的 CanvasGroup 同样隔离；还原原输入状态。
- NumberPresenter：TMP/SDF 粗字体、可读描边和真实终值。显示整数时单调走向目标且不得超报；每种资源独立处理，负变化用明确减号。最终定格后回到真实收据；只缩放文字，不改变显示数值含义。真实星尘才飞钱包。
- Sound/Haptic：由同一 cue 发出原创声音与触觉；暂不从未分析音轨猜测参考音色。支持独立关闭；暂停/跳过取消待执行音效，弱动效和静音不丢结果。

建议一条导演时钟驱动所有曲线；事件ID+cueID确定种子；不同刷新率、暂停、跳过与重播得到一致的终值和阶段。不要依赖 shader _Time 或设备墙上时钟。复用现有对象池、可用材质、网格与质量配置；先验证现有实现的缺口，再改代码。

## 5. 六档与 HORIZON 事件映射

沿用现有六档，具体命名及路由以实际 RewardPlan 为准；下列是建议语义和基础表现时长（不含阅读延时）。

| 档位 | 基础时长 | 触发原则 / 演出 |
| --- | --- | --- |
| Micro | 0.3–0.8s | 普通日常操作、投放确认；小光/回弹，安静说明成本和未来日期 |
| Minor | 0.8–1.8s | 当日真实小成果、恢复；局部光、收据，不全屏爆炸 |
| Combo | 2–4s | 普通 TIME ECHO；清楚来源日、飞行、局部蓄光、兑现 |
| Major | 5–7s | 有实质成果的回声/突破；完整一次十二阶段 |
| Epic | 7–10s+ | CASCADE 多真实节点、较大突破；逐节点释放与收束 |
| Mythic | 10–15s+ | 截止日重要成功、真实多来源合流/长期目标；分段高潮和最终成果展示 |

- 今日行动：消耗、即时收益、未来回声分别列清；未来收益不提前展示为已入账。
- TIME ECHO：来源行动/日期 → 飞行 → 兑现 → 资源落点。
- CASCADE：真实 DAG 拓扑顺序，分叉可同级并列但各节点可辨，合流必须在真实父节点完成后。推荐初始可读节点间隔0.5–0.9s，复杂链允许缩短但不能一闪而过；由实际阅读窗口、用户跳过和性能调整。逐节点点亮、独立脉冲、最终合流；每个节点只展示实际增减，不凭空加倍率。边界、同日事件、缺失父节点按现有规则处理，未知来路不伪造。
- 截止日/长期目标：先逐项展示真实条件和达成/未达成，再总览；不是所有局都庆祝成功。
- Imagine Run/未来预测：明确模拟标签；不用真实奖励计数。
- 负结果：冷色/降温/清晰原因和恢复选项；不套成功火球。恢复本身可以有温暖反馈但不虚构正收益。

## 6. 分期实施（先核心后装饰）

P0-A：审计现有 RewardDirector、RewardPlan.Cues、CinematicEnergy、HorizonImmersion.shader、真实粒子及结果界面；记录当前实际构建/基线录像和差距。统一时间轴、能量包络、主体抖动和暂停。先只做一个可复现真实 TIME ECHO。
P0-B：独立爆炸模块（白光、原创不规则火团、扩散、余辉）；与真实数字同钟协同；构建标准黄金/紫色两种主题，不照搬参考资产。以真实 Unity 连续录像对照五段参考。
P0-C：接入现有事件分级、CASCADE 真实节点逐次演出、当日/延迟收据；保持原经济、存档、重演、暂停、跳过、减弱动效。
P1：制作高品质可授权的六资源实体、金属/PBR/纹理、角色动作与姿势、竖屏构图、音画触觉；建立艺术资产许可与来源记录。
P2：扩大到所有 28 类 DomainEvent 的实际路由（以源码实际清单为准），主题化变奏、性能降档、真机调优和完整验收。不存在真实触发样本的录像明确标 fixture。

## 8. 后续开发约定
