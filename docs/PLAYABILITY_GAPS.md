# HORIZON v0.3 玩法验收清单

以 v0.3 方案与最新玩家反馈为准：本轮继续改进初次操作、三维呈现、强化反馈与结果阅读。功能闭环见 [BUSINESS_ACCEPTANCE.md](BUSINESS_ACCEPTANCE.md)，此表保留设备与真人体验验收。不能用构建成功代替玩家试玩，通过状态以 PR 的对应提交工作流为准。

| 体验 | 当前实现 | 仍需验收或完善 |
| --- | --- | --- |
| 明确操作与规则 | 角色上方的金色接收圈与椭圆判定一致；圈内松手提示、固定日期、目标文字前置、圈外归位、首日手势；点牌说明与按钮备用；日期固定；恢复始终可用 | 真机单手成功率、新玩家能否独立完成首日 |
| 回声与结果 | 实际裁剪后的资源变化、来源与日期；多条结果逐条阅读，实际变化卡片；保留至主动确认；阅读位置、已播放标记与持久领取记录 | 密集回声的阅读节奏、声音与震动辨识 |
| 预测与凝视 | Day 4→7 手绘滑块预测，支持跳过；每日一次凝视，环境音低通与角色减速；累计理解解锁更多信息 | 预测手势、说明和结果对照的真机可读性 |
| 真实三维与奖励 | 有关节的角色、持书或手机、眨眼、行走、触碰与庆祝；曲面网格、弯曲叶片、陶盆、台灯、木长椅、实体地平线；三向光照、接触阴影、Bloom、拖尾、光波；星形星尘、余额计数、外观消费 | 成熟角色与场景资产、动画自然度、手机帧率；奖励节奏是否有吸引力 |
| 第一小时渐进内容 | 第一局保持简单；第二局加入三张新牌与四个日常情境；第三局二阶事件与未来自己揭示 | 15/30/50 分钟的实际玩家节奏、平衡和重玩意愿；不能从自动化推断“有趣” |
| 多来源因果与 CASCADE | 支援和成长可合流；行动、回声、机会、门连接成图；多父节点存档；七层起展示网络 | 更广泛的规则、丰富的分叉和非重复内容；密集网络可读性 |
| 未来站 | 默认约 46 秒，支持随时点击或上滑推进；保存当前段落；个人记忆亮起，未来自己行走触碰；第三次选择想保护的行为 | 情感感染力与每局差异；自动播放的时间不能等同于完整情感体验 |
| 截止日 | 新局能力门同时检查两次已返回成长，状态门检查两次恢复；支援门检查关系、金钱与支援行动；三门连接历史证据 | 原型数值与轨迹标准的平衡、明确的失败原因、真机重开时间 |
| 分支探索 | 用实际规则重演多天替代选择；机会消失后默认恢复；显示三门与资源前后差异；原档案和奖励不改写 | 更丰富的分叉编辑与因果解释；当前不是可撤销已玩人生 |
| 时间地图与档案 | 每天可点开详情；拖动因果网络；按标题、行动、局数查找与筛选；手动改名 | 中文输入法、长档案滚动、跨局故事的长期吸引力 |
| 第一周与展望 | 不同回访日期累计七章，不要求连续、不重置；第五章范围观察、第七章 30 天展望均呈现六资源；24 组真实规则模拟 | 章节一至四可独立选牌练习、六比较不同走法；七的长期新牌与三维自己仍是展望，尚非完整七天剧情和三十天战役 |
| 未来的不确定性 | 范围来自不同后续行动的模拟，明确说明假设；已埋回声按原规则抵达 | 新牌池第三局已有独立天气和邀约事件、固定存档种子及概率说明；仍需扩大世界内容和验证平衡 |
| 十秒分享 | 实际 Unity Canvas 导出 540×960、60 帧 GIF；三节点到全网络；文案的截止日因果声明经反事实重演；Android 10+ 相册与系统分享入口 | Android 真机相册和目标应用兼容性、编码耗时与低端机体验；旧设备只保留本地文件 |
| 低频惊喜 | 3–5 局间隔、持久记录；真实旧记忆、多回声风暴；新无因之果 D6 先收到真实余力，D9 揭因，原因替换时分支结果消失，旧局保留记忆版 | 更丰富的惊喜剧情与特效仍需完善 |
| 旧存档 | 旧资源与图迁移，保留旧局牌池、门槛与重演规则；待确认结果与未来站段落恢复 | Android 实际升级安装与长时间存档测试 |
| 产品原则 | 无断签惩罚、强迫日常、付费准确率、付费撤销；奖励用于外观 | 持续遵守，当前未接入商业化 |

业务与交互功能通过状态由 73 项 Unity 检查及 Android 构建；后续需要实机触控/帧率/分享、首次玩家观察及内容平衡。成熟 3D 资产、动画自然度、核心动效和情感演出继续迭代。本轮尚未获得真实玩家数据。

完整 0–35 节映射、取舍与理念边界见 [V03_ACCEPTANCE.md](V03_ACCEPTANCE.md)。本轮描述不替代对应提交的 CI、真机和首次玩家验收。
