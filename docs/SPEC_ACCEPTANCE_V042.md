# v0.4.2 逐章产品验收

唯一基线：[Master Product Specification v0.4.2](MASTER_PRODUCT_SPEC_V0.4.2.md)。本表审核的是玩家能否玩到方案描述的行为，而不是类名、按钮或模式名是否存在。仓库当前是**可玩的规则与体验原型，尚未完整实现 53 章产品方案**。

“闭环”表示表内限定范围可以通过选择、结算、保存和再次进入完成；“部分”表示有代码和可操作内容，但仍有具体产品缺口；“未实现”表示缺少该章的重要交付；“待玩家验收”不能由自动测试代替。相邻章节的交付范围可以不同。

## 当前主流程

首次直接进入三张宽卡 → 每天点牌或向上拖牌 → 今天的实际结果 → 玩家安排的回声日期和来源 → 同日回声集中展示 → 第 4 天预测 → 对照实际结果 → 展示日准备 / 截止日 → Future Station / 时间地图 → 再走一条人生。两页规则说明改为主动查看，普通奖励与回声合并展示，Mythic 保留独立演出。日期区域显示玩家真实安排的回声，不用空的问号时间点代替信息。

第 3 天起可为当前牌预演、选择准备方法、练习失败与恢复，然后回到原牌。预演与实际行动的分歧自动保存；真实受挫后下一次行动继续对照恢复方法，没有发生的困难保持待观察。模型只累计观察证据，不给玩家永久标签，也不把游戏选择当成现实成就。

锁定后显示按行为家族生成的具体步骤。一次点击推进准备，再亲自选择执行，避免四次相同的确认。匹配的 Trigger 与完成准备后的行动条件至少 6 时，负精力成本最多减 1；预约、押金和票需要 1 金钱，缩小准备需要 1 专注并降低 2 摩擦。准备作用进入实际资源与因果图，重复或支付不起的装备不改变状态。多数提示仍共享效果，移除装备、环境变化与进一步平衡尚未完成。

帮助与主页可进入隔离练习局，使用正式规则。它在内存中运行；退出或重启恢复原人生，练习不会写入正式存档。当前旧局不用结束即可试用新界面和新牌池。

旧牌池版本 7/8 的人生、存档和回放保留原规则；新局使用牌池 9、规则 10。首局只常显精力、心情与能力，其余资源可在目标/全部状态里看见。查看安排不揭示隐藏二阶来源。自定义、未关联行动的预演尚无自动校准。

本轮详细问题、修复、验证范围见 [试玩与跑通审计](PLAYABILITY_AUDIT_V042.md)。机器报告由 `tools/build_product_acceptance.py` 将本表与同提交 NUnit 结果合并；有相关测试不意味着整章完成。

## 接下来必须先完成的产品工作

1. 让首次玩家无说明完成一次“现在选择 → 回声回来 → 预测对照 → 困难恢复”，测出卡住的具体屏幕和原因。
2. 深化已经接入成本的 Action Engine/Trigger：添加提示更换、环境变化、念头的真实规则和目标专属策略。
3. 扩展已有预演/游戏行动对照到自定义目标与现实时间线，并用分歧改变下次想象内容；让 Mirror Run 主动重现个人节点。
4. 扩展独立 Boss、路线、世界观、知识技能、目标过程和多个 Future Self。
5. 制作多时间线 Pattern Broken、Reality Convergence、Orbit 升级的专属演出；真机验证音频与震动。
6. 最后交付在线 Parallel Lives / Future Messages、MP4 分享和长期内容。账户、在线服务与支付未在当前原型中部署。

每项完成后更新本表的状态、真实玩法入口和验收证据。测试通过只说明所覆盖规则与流程按预期运行，不证明整体好玩、直观或完成了产品愿景。
