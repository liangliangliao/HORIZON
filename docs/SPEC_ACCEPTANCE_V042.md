# v0.4.2 逐章产品验收

唯一基线：[Master Product Specification v0.4.2](MASTER_PRODUCT_SPEC_V0.4.2.md)。本表审核的是玩家能否玩到方案描述的行为，而不是类名、按钮或模式名是否存在。仓库当前是**可玩的规则与体验原型，尚未完整实现 53 章产品方案**。

“闭环”表示表内限定范围可以通过选择、结算、保存和再次进入完成；“部分”表示有代码和可操作内容，但仍有具体产品缺口；“未实现”表示缺少该章的重要交付；“待玩家验收”不能由自动测试代替。相邻章节的交付范围可以不同。

## 当前主流程

首局两页引导 → 明确截止日准备 → 每天点牌或向上拖牌 → 今天的实际结果 → 玩家安排的回声日期 → 回声抵达与来源 → 第 4 天预测 → 对照实际结果 → 截止日 → Future Station / 时间地图 → 再走一条人生。

第 3 天起，成长选择可以直接预演一次失败与恢复，完成后回到原牌；也可以锁定决定并进入步骤执行，返回时继续原来的行动。第 5 天起，默认 12 天模式逐步出现新家族牌，保留成长和恢复选择。“准备行动环境”实际装备闹钟；“预演失败后的明天”必须完成当日、对应行动的预演才可使用。受挫后的主界面根据真实状态提示恢复与再战。主界面常显当前资源、三项准备进度和最近回声，预测支持点击加减与拖动。

旧牌池版本 7 的人生、存档和回放保留原手牌；新局使用牌池版本 8。引导和查看未来安排不推进时间，不结算资源，不揭示隐藏二阶来源。想象完成不自动选择卡牌，不自动生成现实成就。

| --- | --- | --- | --- |
| 1 | 游戏是什么 | 部分：卡牌时间策略、因果回放和模式原型；`GameSession`、`PatternEngine` | Roguelite 构筑、更多人生故事，证明前两层单独好玩 |
| 2 | TIME / FORESIGHT / IMAGINATION / PATTERN | 部分：时间结算闭环；后 3 项有规则与界面 | 八级信息成长、个性化想象和模式重现的完整体验 |
| 3 | 统一核心循环 | 部分：主局、预测、预演、执行、现实桥梁可操作 | 困难、调整、模式、Future Self 与现实比较尚未形成全自动连续主线 |
| 4 | 12 天及扩展局 | 部分：12/30 天可完成，8 个模式有入口；`StartMasterLife` | Long Run 目前也是 30 天；各模式须有独立内容、平衡；15–25 分钟待真人测量 |

## 接下来必须先完成的产品工作

1. 让首次玩家无说明完成一次“现在选择 → 回声回来 → 预测对照 → 困难恢复”，测出卡住的具体屏幕和原因。
2. 将 Action Engine、Trigger、Thought Monster 从解释面板变成有代价、有结果的准备策略；为不同决定生成具体执行路径。
3. 实现想象/现实时间线对照页面和分歧记录；让 Mirror Run 重现有跨局证据的个人节点。
4. 扩展独立 Boss、路线、世界观、知识技能、目标过程和多个 Future Self。
5. 制作多时间线 Pattern Broken、Reality Convergence、Orbit 升级的专属演出；真机验证音频与震动。
6. 最后交付在线 Parallel Lives / Future Messages、MP4 分享和长期内容。账户、在线服务与支付未在当前原型中部署。

每项完成后更新本表的状态、真实玩法入口和验收证据。测试通过只说明所覆盖规则与流程按预期运行，不证明整体好玩、直观或完成了产品愿景。
