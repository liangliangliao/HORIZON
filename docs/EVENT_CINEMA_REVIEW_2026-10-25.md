## 为什么此前差距仍大

1. 参考先让主体做一件事，再揭晓结果。此前 HORIZON 常先展示通用台座、光环、资源纪念物，缺少“这个人究竟做了什么”的开端。
2. 参考主体持续微动、局部光逐渐增强，短促释放后重新稳定。全程相近亮度、均匀射线、不断换字幕，会消耗反差，而非积累期待。
3. 特写不是把整个世界推近。透视会把日期、人物、物件挤到一起；只保证主物件不出框，也不能证明全景完整。
4. 参考大结果占最高视觉层级。旧主结果、标题、来源、说明、三维日期相互竞争。
5. 程序化模型、动作和通用材质与商业项目的专门建模、美术、表演仍有差距。增加 Bloom 和时长不能消除此差距；测试覆盖率不是视觉分数。

## 可迁移的视觉语法

| 参考细节 | 感受来源 | HORIZON 对应实现 |
| --- | --- | --- |
| 稳定主体、外围较暗 | 知道要看哪里 | 实际行动先出现，标题与阅读区避开主体 |
| 小幅往复、由弱到强的局部光 | 事件尚未完成 | 独立蓄势窗口、有限拉扯、核心暖光与向内光膜 |
| 放慢细节、静止与静音 | 揭晓有分量 | 日常行动至少 0.62 秒停顿，重大事件保留原有停顿 |
| 短促释放与外扩射线 | 明确的揭晓瞬间 | 同一导演 cue 控制光、声音、震动；光膜中心留空 |
| 结果弹出、扫光、稳定停留 | 看懂变化及归属 | 每项真实资源独立 2.8 秒，接着显示披露过的后果 |
| 揭晓后仍有完整画面 | 把细节放回情境 | 包围盒求解的结尾全景及手动镜头切换 |

等待揭晓是表现方式，不引入随机奖励、付费概率、虚构倍率或额外结算。负变化仍是负变化；预演不是现实收益。

## 事件分镜与镜头

- `LifeActionStoryboard` 只消费不可变收据的原行动名称。散步、休息、阅读、工作、联系、收入、消费、计划、探索、练习共享对应场景模块；不宣称每张卡已有独立影视级角色动画。
- “出去走走”：推开家门 → 沿小路走进公园 → 停下来呼吸 → 光聚向行动主体 → 停顿 → 实际精力/心情变化 → 原先披露的后果 → 回到全景。
- 行动开头至少 12 秒，包含约 7.2 秒地点/动作与后续蓄势；开门一句至少 2.2 秒、抵达一句至少 2 秒，第一次冲击到主结果至少 3.2 秒。现有跳过始终可用，不把长动画变成强制等待。
- 消息主题只表现发出联系，不提前保证朋友已回应。阅读/计划用书与笔记，工作用任务屏幕，消费用手机，恢复用座椅。未知行动回退到一般操作，不假造职业或结果。
- 散步预演也使用家门/公园，但仍经历原准备、努力、困难、失败、恢复、再行动状态机；状态始终标注为预演。
- 全景用实际可见网格包围盒及最窄 20:9 手机视口求解，特写只对当前动作/资源；开场、抵达、结尾不再同一距离。电影及预演提供“查看全景”切换，不改导演时间和收据。

## 版式与停留

- 时间回声不再给每个三维节点悬挂一个大日期；当前日期、行动、来路由固定字幕解释。
- 结果汇总是独立不透明阅读页，不把黑卡压在三维角色上。播放电影时整页让位给全屏场景。
- 截止日历史不同时绘制全部跨天连线；每日行动、三类条件、继续按钮分区呈现。
- 因果链是可滚动单列，不在一屏塞满十二条小字；保留原始实际来路。
- 网络总览按日期分组单列展示，点选后标明“来源 / 当前 / 后续”，可只看直接联系，不画全连接网。
- 截止日行动回看和因果链完成后，等待真实点击，不再自动消失；有短暂防误触及页面代际保护，不重复发星尘。
