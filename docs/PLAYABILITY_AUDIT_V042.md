# v0.4.2 试玩与跑通审计

结论：**方案没有全部实现，也没有全部验证跑通。** 当前版本可以完成一局、保存恢复和重演，但存在独立 Boss、个人模式重现、在线社交、现实时间线及最终演出品质等明确缺口。53 章的逐项状态与剩余工作见 [产品验收矩阵](SPEC_ACCEPTANCE_V042.md)。有面板、类或成功构建不等于功能完成。

## 本轮发现的体验断点

| 实际问题 | 本轮处理 | 限制与验收 |
| --- | --- | --- |
| 主界面大块说明遮住角色，三列窄卡难比较；无回声时显示多个问号 | 改为三行宽卡，今天成本和回声日期/意义同屏；只显示玩家实际安排的未来；短情境提示替代大块文字 | Unity 竖屏截图与主要触控区域检查；不同手机、单手拖动与字号仍待真机 |
| 开始前强制读两页、密集回声逐页确认、普通奖励不断打断 | 直接开始行动；帮助按需查看；同日回声集中、可滚动看全部来源，也可逐条查看；普通奖励合并，Mythic 独立呈现 | 每份收据保存，继续仅处理反馈；不会自动选牌。具体阅读时间、音乐辨识和疲劳感待玩家 |
| Decision Lock 通用步骤需要四次重复点击，准备没有实际收益 | 按行为家族生成具体步骤；一次推进准备，再亲自执行。匹配提示与完成后的条件达到 6 时最多省 1 精力；部分提示需要金钱，缩小准备需要专注 | 新牌池 9 才启用；旧局不变。多个提示仍共享效果，环境与个性化策略未完整完成 |
| 预演是通用故事，完成后看不到实际从哪一步不同 | 选择最小一步、固定时间或共同准备，遇到对应挫折；关联当前牌后自动对照实际选择与恢复，保存节点证据和近期校准计数 | 只比较真实发生的游戏行动；未发生的失败保持待观察。现实动作另在 Reality Bridge 由本人报告 |
| 在当前旧局中难以尝试新版本，重开可能丢进度 | 添加隔离练习局，帮助/主页可进入；与原人生分开，原档案保留；退出或重启恢复原人生 | 练习在内存中运行，不写入正式存档，练习进度不跨启动保留 |
| 准备节点很多时，一张行动也可能被叫作 CASCADE | 新局要求至少两个真实行动合流；单行动的锁定、步骤、想象不单独算超级 Combo | 真实多行动内容与专属逐节点演出还需扩展 |
| 快速进入或退出练习局时，尚未结束的卡牌动画访问已销毁界面 | 动画在每次让出帧后检查界面代次及对象是否仍存在，页面切换后停止旧动画 | 练习、返回原人生和连续重建界面由 Unity 场景覆盖 |

旧牌池 7/8 的执行确认也缩短为一次推进四步，保留原有命令顺序及结算。提示与降低摩擦的旧局界面明确描述原规则，不显示新局才有的收费、精力折扣或多因子收益。

## 已执行的验证与本提交 CI

本地规则套件 157 项通过，包含新增 18 项玩法规则审计；DeepSeek/Azure 网关 23 项模拟服务测试通过。Unity 参考程序集编译通过，仅证明 C# 类型检查，不能代替 Unity 运行。

`PlayabilityAuditTests.EveryModeCompletesBalancedAndRecoveringLivesWithResumeAndReplay` 在 8 个模式、4 个种子、2 种策略中完成 64 条人生。每天结算后和次日都进行 JSON 保存/恢复，结束后按原规则重演，对照门、精力、能力和关系，检查因果图缺失父节点/循环。32 条均衡策略均完成三项准备；恢复策略能安全结束。每种模式的完整记录输出到 `artifacts/playability/*.csv`。**这不证明 8 个模式已有独立内容**：Long Run 当前为 30 天，在线 Parallel Lives 也尚未实现。

新增 Unity Play Mode 场景实际点牌走完 12 天，包含集中回声、锁定/提示/降低摩擦/执行、预测与回顾、未来站及截止日；检查结果确认次数、宽卡触控尺寸和完整人生结算。另一条流程预演后作出不同选择、查看校准、进入练习并模拟应用暂停，核对正式存档文件逐字节不变，退出后恢复原人生。所有 Unity 结果、63 张 PNG、10 秒 GIF 和 APK 由同提交 CI 输出，实际通过结果以 [PR #3](https://github.com/liangliangliao/HORIZON/pull/3) 的检查与产物为准。

`tools/build_product_acceptance.py` 读取 53 章矩阵和同提交 NUnit XML，输出 `artifacts/product-acceptance.json`，列出已执行的相关子集与每章剩余内容。它明确保留 `all_specification_features_implemented=false`、`all_specification_features_verified=false`；不会用测试数量换算产品完成百分比。

## 尚不能确认跑通的范围

| 范围 | 当前事实 |
| --- | --- |
| 第一次玩是否直观、15–25 分钟是否有趣 | 尚无首次玩家观察和完整真机试玩数据；自动点击不能作此结论 |
| Android 真实操作、升级、分享、性能、音频和震动 | APK 编译及包结构/架构/签名证书检查与实际设备运行是不同证据；真实设备仍待验证 |
| DeepSeek / Azure / Foundry 线上请求 | 配置、终结点归一化、取消、超时、服务错误和内容边界已验证；未用用户自有凭据发起真实服务请求 |
| 独立 Boss 与互斥路线 | 可玩结算仍是截止日三项准备；10 种 Boss 尚无完整独立规则 |
| Mirror / HORIZON ME / Knowledge / Worldview | 有有限模式与知识阶段；未全面形成个人复现关卡、世界观改变情境和多技能挑战 |
| 想象与真实生活全面校准 | 本轮为关联当前牌与实际游戏行动；任意目标、真实生活完整线和下次 AI 困难情境更新尚未完成 |
| Mythic / Future Self / Orbit 的最终品质 | 程序化原型可呈现；多条旧人生碎裂、角色版本升级、专属声画镜头尚需制作 |
| 社交与视频 | 仅本地同起点比较、消息复制导入、10 秒 GIF；没有在线双方会话/投递，也没有 MP4 音视频编码 |

完成下一项应以玩家可走到的流程、规则证据、保存恢复和对应验收为准。剩余工作须继续迭代，不能把这次修复当作全方案交付。
