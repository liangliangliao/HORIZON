# Energy Cinematic V3.0 实现与验收

基于 Android APK 工作流 #201 的 `codex/immersive-animation-language`，基线提交 `1e9ec08b7969822503782e96079ba9495a8dc477`。这一轮聚焦「试着求助」和「整理作品」预演完成后的真实入账。两张牌共用箱体，保留各自的原场景和真实回执。验收录像使用同一条「试着求助」记录。 [V3.0 规范](ENERGY_CINEMATIC_V3_VISUAL_REBUILD.md) · [基线构建 #201](https://github.com/liangliangliao/HORIZON/actions/runs/45799240433)

0–2.9 秒按三波曲线驱动箱体和蓄光，2.9 秒释放，3.13 秒开始显示收益，4.30 秒显示实际成本，5.50 秒进入可继续查看的行动回执。提前查看回执时直接显示已保存的完整结果。火焰图集为本项目原创，由 `tools/build_case_flame_atlas.py` 离线生成。Unity 采证沿用项目中的箱体、角色、道具和入账流程。

时间回声使用记录中的行动印记和固定落点，多个收益一同读数。未来轨道按真实掩码连续点亮，能力使用透镜、关系使用双轨、财富使用储备箱。「走进未来」的角色接近、触碰并穿过实体门，想象预览保持温和。因果连锁按已观察的父边传递，合流光效定位到真实合流节点。
