# CASCADE 真实因果中继演出

基于最新 `feat/3d-jackpot-animation@b3de7b6`，继续沿用 Master v0.4.2、Reward System v1.0 与 Cinematic & Animation v1.0。

参考 25 秒奖励视频中多个主体依次亮起、光柱爆发、最终汇聚的节奏。HORIZON 使用实际行动与回声节点组成三维中继器：金属底座、光环、节点核心、交叉光柱和真实父节点连接。素材对应既有因果网络，不增加新玩法或奖励种类。

- 光柱与节点音效、震动共用原导演 NodeHit 时间；保留 0.35 / 0.28 / 0.21 / 0.15 秒加速和末节点后的 150ms 停顿。最终网络亮起后接入原主体、倍率牌和结算。
- 新事件在结算时复制可观察父节点关系。两个独立行动不会按日期先后被画成彼此导致；真实分叉与合流按记录连接。
- 每次显示一个实际节点的日期与完整来源，原标题、说明及资源文案继续显示。主体特写时来源浮签让出画面，避免与倍率牌重叠。
- 最多 24 个中继器、64 条连接，重复播放复用模型与材质。省电保留全部来源和连接，只限制同时显示的装饰光柱；减弱动效使用静态亮环。光柱不依赖 HDR 或 Bloom，GLES3 使用同一着色器，流动只读取导演时钟。
- 暂停冻结光柱、光环与节点；跳过及取消清空演出。新字段只保存演出证据，不更改资源、奖励额度、概率或胜负。旧收据没有父节点记录时保留节点，不臆造连接；隐藏来路仍不展示其父节点。

便携测试 `CausalRelayTests` 验证真实 Long Run 的 CASCADE / Causal Singularity、多父节点、快照与存档、隐藏来源、旧收据、暂停和对象上限。`CausalRelayRenderingTests` 在 Unity 中验证实际事件、光柱着色器、暂停、减弱动效、清理和原文保留，输出 `artifacts/cinematics/causal-relays-*.png` 及 360×640 / 20fps 动图。

Android 开发检查包另外从原规则生成两种因果事件，在实际 GLES3 后缓冲中录制首次光柱与最终汇聚画面，检查材质支持和演出返回。验证脚本要求这四张原生截图齐全。

验证必须对应本轮提交。实际 Unity 输出、Android 构建及原生检查通过前，不把本地规则测试当成渲染成功。模拟器兼容检查也不代替真机帧率、美术、音效和触觉体验验收。
