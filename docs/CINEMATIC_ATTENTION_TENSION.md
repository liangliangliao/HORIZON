# 注意力、蓄力与悬停

针对 `VID_20261011_191037.mp4` 的体验反馈，本轮调整奖励演出的注意力与时间对比：观众先看清一个实体，再看到它积蓄能量、停住、释放；随后重新收拢到最终主体，延迟揭晓。沿用 HORIZON 既有因果节点与奖励资产。

- CASCADE / Causal Singularity 开场从第一个实际来源节点的近景开始。镜头缓慢推进，机械光环下压、核心增亮；背景建筑、光环与星粒让出视觉中心。第一节点启动前加入最多 220ms 的收声与悬停，然后按原节点时刻拉开镜头。
- 二次揭晓前最多 1.25 秒，让最终因果链主体提前以尚未连接的状态进入镜头，逐步收紧画面并压低因果光柱与外圈光晕。Epic 在揭晓前悬停 340ms，Mythic 悬停 480ms；随后连接、光波和节点音效同时释放。
- 主体特写时压低其余节点、路径与背景建筑，来源浮签与倍率牌暂时让出最终主体，揭晓后倍率牌恢复；因果演出隐藏旁观人物的渲染并在结束时还原。所有实际节点和连接仍保留在同一网络中。
- 两次蓄力使用游戏内合成的上行音效；悬停切断触发音和环境底音。镜头、视角、主体、取样动画、着色器、角色和粒子同时停住，导演继续计时，既有事件时刻保持不变。
- 原六级时长、节点间隔、终点 150ms Hit Stop、标题、说明、来源、预测收据及实际结算保持原方案。新增悬停只属于演出，不改变奖励、概率和展示倍率。
- 减弱动效绕过新增推进、压缩和悬停；暂停、跳过与取消继续统一处理并还原画面。

`CinematicTensionTests` 验证原节点、终点停顿与不可变来源；`CausalRelayRenderingTests` 在实际 Unity 相机中检查悬停期间主体与镜头不动，并验证游戏触发音效在悬停区间为零、在蓄力和释放时存在。导出 540×960、20fps 全色帧与同一触发音的 22050Hz PCM，用于有声视频审核。

技术验证能确认节奏执行和兼容性；沉浸与期待的主观效果仍应通过实际播放与体验评审判断。
