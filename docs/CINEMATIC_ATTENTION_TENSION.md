# 注意力、蓄力与悬停

针对 `VID_20261011_191037.mp4` 的体验反馈，本轮调整奖励演出的注意力与时间对比：观众先看清一个实体，再看到它积蓄能量、停住、释放；随后重新收拢到最终主体，延迟揭晓。沿用 HORIZON 既有因果节点与奖励资产。

- CASCADE / Causal Singularity 开场从第一个实际来源节点的近景开始。镜头缓慢推进，机械光环下压、核心增亮；背景建筑、光环与星粒让出视觉中心。第一节点启动前按级别加入 320 / 450 / 580ms 的收声与悬停，然后按节点时刻拉开镜头。
- 二次揭晓前保留 1.25 / 1.65 / 2.10 秒预览，让最终因果链主体提前以尚未连接的状态进入镜头，逐步收紧画面并压低因果光柱与外圈光晕。Major / Epic / Mythic 在揭晓前分别悬停 400 / 600 / 780ms；随后连接、光波和节点音效同时释放。
- 主体特写时压低其余节点、路径与背景建筑，来源浮签与倍率牌暂时让出最终主体，揭晓后倍率牌恢复；因果演出隐藏旁观人物的渲染并在结束时还原。所有实际节点和连接仍保留在同一网络中。
