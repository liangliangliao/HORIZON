# 《HORIZON / 远见》v0.3 逐项验收

对照用户提供的 0–35 节方案，以及后续关于操作不清晰、三维不足、奖励弱和结果一闪而过的反馈。**现在仍不能宣称 v0.3 全部完成，或已经证明好玩。**“原型实现”表示有实际规则和可操作入口，不代表美术、设备表现或情感体验达到正式产品标准。

本轮在最新分支的六资源范围观察之上继续开发：规则版本 5、牌池版本 3。旧人生保留原牌池、门槛、效果和重演规则。新规则在第三局加入独立环境事件；存档固定每局事件种子，读取、观察、分支研究不会重新抽取真实世界。

## 理念检查

- 行为有可追溯的实际后果；结果解释使用封顶后的真实变化。旧档案缺少逐项数据时明确标注，不编造原因。
- 世界事件与玩家种下的回声分开：已埋回声按日期兑现；概率用于天气和邀约。观察、读档与研究不会重抽真实事件。
- 理解解锁信息，星尘解锁外观。预测和分支探索不增加能力、货币或成功率，也不覆盖已经走过的人生。
- 快乐也能产生正面余温。规则不会把所有娱乐统一定义成惩罚，恢复始终有合法选择。
- 失败结果与关键记忆等待主动确认；重開才启动短过渡，不能把重要信息一闪而过。

## 验证入口与边界

新增 `ObservationDesignTests` 检查旧规则、世界变化/存档一致性、信息权限、预测原因合计、真正的 30 天内容、模拟隔离。`PlayableFlowTests` 操作真实 Unity 视图，覆盖预测解释、概率、六轨状态、观察练习、两位可能自己、跨局档案、十二天星图、记忆保存与一次揭因。CI 要求全部规则测试通过，并独立解码 22 张 1080×1920 画面和实际十秒 GIF，之后才构建双架构 APK。

文档描述实现范围；**测试通过状态以对应提交的 CI 为准**。代码或截图不构成正式美术验收，不构成 Android 实机性能验收，也不构成真实玩家对乐趣、易懂程度、节奏或学习效果的认可。下一轮产品验收需要手机试玩、首次玩家记录、成熟角色和环境资产、动画调校与内容平衡。
