# v0.4.2 可玩扩展验收说明

这批改造继续使用 v0.4.2 作为唯一产品基线。完整 53 章、207 项固定验收定义见 [SPEC_ACCEPTANCE_V042.md](SPEC_ACCEPTANCE_V042.md)；构建根据实际运行证据生成 JSON，不以入口数量宣布完成率。

## 玩家能实际做什么

- 在 12/30/60 天和不同人生模式里安排资源、路线与延迟回声；十种 Boss 使用不同的准备条件。
- 从三张立体扇形手牌中点开查看，或拖入未来圈行动；可用性受真实成本约束。
- 锁定决定后执行步骤，装备和拆卸 Trigger；降低摩擦、调整替代奖励，处理六种思维怪物。
- 使用八项知识的 IF/THEN 条件和最多三种世界观；知识从识别到模拟、现实执行再到经验，不能直接跳级。
- 预演职业、健康、关系或学习目标，选择 1/2/3/4 次必须恢复的失败；虚拟状态消耗和上次分歧改变下一次过程。
- 在 Mirror Run 重现近期断点，以真实恢复和成长动作突破；Overdrive、四种投资池、CASCADE 与隐藏来路由规则触发。
- 在未来站选择不同未来自己，回看实际因果片段；现实星座可追溯想象、模拟和本人报告的真实动作。
- 使用可选 AI 内容工作室；分享实际 10 秒有声 MP4 或 GIF；自建 HTTPS 服务支持两人同起点和未来留言。

## 验证边界

规则运行与领域事件先决定结果，UI、声音、震动和动画订阅结果。AI 内容不能修改资源、概率、Boss 或现实完成状态。真实手机上的触摸、性能、震动和 Android 硬件编码仍需实机验证；编辑器交互不替代这些证据。当前没有付费模型凭据和公网社交实例，不能宣称它们已联通。

207 项按章等权，未验证记零，已知部分实现上限 0.5。大于 85% 的门槛表示实现且有执行证据的综合工程覆盖，不表示所有功能已完成，也不证明玩家满意度、留存或现实行为改变。
