# HORIZON / 远见

Unity 竖屏人生卡牌原型，基于《HORIZON / 远见》v0.3。每天选一张行动牌，今天的变化立即发生，延迟回声在卡牌标记的日期回来。第 12 天，过去的选择共同回答能力、状态与支援三道门。

## 怎么玩

1. 使用 **Unity 2022.3.22f1** 打开仓库，打开 `Assets/Scenes/Boot.unity` 后 Play。Game 视图使用 **1080×1920** 或 9:16。界面、场景及角色由运行时代码创建。
2. 首次进入点击「看看」。每天从三张牌中选一张，**拖进发光圈，圈变色并提示「松手确认」时松手**。圈外松手会让卡牌归位，不消耗资源。也可以点牌阅读说明，再点「使用这张牌」。
3. 拖动高度不会改变日期。卡牌说明今天的变化及第几天回来；资源不足时点牌查看原因。恢复牌始终可用。
4. 行动、回声结果保留在屏幕上，点击继续才推进。结果说明实际变化、来源与未来日期。关闭应用后未确认的结果会恢复，星尘不会重复发放。
5. 右上角「目标」解释三道门及当前进度。主界面突出精力、心情、能力，完整六资源在目标面板中查看。第 12 天能力需 ≥6；状态需精力、心情各 ≥4；支援需两次支援行动、关系 ≥6、金钱 ≥2。
6. 第 4 天可拖动三个滑块，预测第 7 天的精力、心情、洞察变化，也可以「先玩下去，暂不预测」。当天行动后通过按钮或上滑靠近未来的自己；做过预测时第 7 天查看预测与真实结果。
7. 第 12 天三维门依次响应，随后保留通过与未通过的条件。主动查看可能分支或时间地图，点击「再试一条时间线」后约 1.1 秒进入第二局。

## 三维与奖励

`HorizonWorld3D` 构建真实三维场景：现在与未来的同一角色、书桌与书本、手机、休息花园、朋友、长椅、城市、地平线光门和截止日三道门。相机、灯光、雾、边缘光与发光材质参与实际渲染。图形与声音随仓库生成，无需下载付费素材。

每次行动获得 1 星尘；普通回声 3；连锁按实际路径层数；截止日获得 5＋每点亮一门 8。反馈包含三维飞散、飞入钱包的光点、分层音效与震动。右上角钱包可解锁黎明（25 星尘）与极光（60 星尘）配色，已解锁外观再次切换免费。星尘用于外观，预测成功仍主要扩大信息可见性。

内置 `HorizonSansSC.ttf` 基于 Noto Sans SC 制作，覆盖 GB2312 常用字符及当前游戏文本；来源、制作说明与 SIL OFL 授权随仓库保存。运行时按安全区域布局并请求竖屏。

## 因果与长期记录

- 六资源进入即时效果、延迟回声、条件投影、存档与三门结算。
- 每天可长按未来 0.65 秒凝视一次。第二局解锁 HORIZON II 的节点类型信息；第三次未来站解锁 HORIZON III 的两条条件未来。
- 预测接近实际结果累计 1、3、10 次，分别解锁方向、强度、二阶来源，只扩大信息可见性。
- 第三局起，透支可能让邀约缺席，高洞察带来「接住机会」，关系回应带来「并肩准备」。改写后的行动与新回声继续沿原来的因果路径成长。
- CASCADE 根据实际因果路径计数并加速，七层起展示因果网络。存档保留父子节点和已兑现状态。
- 第三次未来站揭示未来的自己；玩家选择想保护的近期行为，后续凝视信息据此标注。
- 时间地图收藏完成的人生，可修改标题。失败分支按同一套规则重演单次替代行动，如实显示仍未通过的门。
- 旧三资源及旧因果图存档会迁移。

## 验证与构建

Unity Test Runner 的 EditMode 中运行全部测试：

- `GameSessionTests`：资源、回声、预测、存档迁移、三种选择事件、九层路径、三门及幻影重演。
- `PlayExperienceTests`：光圈椭圆边界、固定日期、可选预测、奖励存档、外观消费。
- `PlayableFlowTests`：进入真实 Play Mode，操作拖拽与按钮，验证结果停留及恢复、未来站、截止日与重开；输出 1080×1920 的实际 Unity 渲染截图。

Linux 无显示器时需 Xvfb 和图形设备，渲染测试不能使用 `-nographics`：

```bash
Unity -batchmode -force-glcore -projectPath . -runTests -testPlatform EditMode -testResults TestResults.xml
```

`.github/workflows/android-apk.yml` 在 PR 更新时先执行上述测试与截图，再通过 `Horizon.Editor.AndroidBuild.Build` 构建 IL2CPP Android APK，包含 ARMv7 与 ARM64，并校验两种架构的原生库。产物 `HORIZON-EditMode-Results`、`HORIZON-Unity-Portrait-Previews`、`HORIZON-Android-APK` 保留 14 天。试玩 APK 使用开发签名；正式发布需另配签名。

工作流使用仓库已有 Unity 授权密钥。首次配置时 Personal 需要 UNITY_LICENSE、UNITY_EMAIL、UNITY_PASSWORD；Pro 需要 UNITY_SERIAL、UNITY_EMAIL、UNITY_PASSWORD。

## 实际边界

三维模型、音效与动作仍是程序化原型。实际截图和规则测试不能证明游戏已足够有趣；触控成功率、反馈辨识、阅读时间、帧率和重玩意愿需要手机试玩。未来站尚未达到方案中 40～60 秒的完整情感演出；多父因果、广泛内容池、可信概率、分享动画和第一周长期成长尚未实现。详见 [验收清单](docs/PLAYABILITY_GAPS.md)。

下一步优先验证新操作与结果反馈，再打磨角色、动作、材质及未来站演出。
