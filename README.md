# HORIZON / 远见

Unity 竖屏人生卡牌原型，基于《HORIZON / 远见》v0.3。每天选一张行动牌，今天的变化立即发生，延迟回声在卡牌标记的日期回来。第 12 天，过去的选择共同回答能力、状态与支援三道门。

## 怎么玩

1. 使用 **Unity 2022.3.22f1** 打开仓库，打开 `Assets/Scenes/Boot.unity` 后 Play。Game 视图使用 **1080×1920** 或 9:16。界面、场景及角色由运行时代码创建。
2. 首次进入点击「看看」。每天从三张牌中选一张，**拖进发光圈，圈变色并提示「松手确认」时松手**。圈外松手会让卡牌归位，不消耗资源。也可以点牌阅读说明，再点「使用这张牌」。
3. 拖动高度不会改变日期。卡牌说明今天的变化及第几天回来；资源不足时点牌查看原因。恢复牌始终可用。
4. 行动、回声结果保留在屏幕上，点击继续才推进。结果说明实际变化、来源与未来日期。关闭应用后未确认的结果会恢复，星尘不会重复发放。
5. 右上角「目标」解释三道门及当前进度。第一局突出三种状态，第二局起显示六个圆轨；正常数字默认隐藏，拖牌或低资源时显示，完整状态可在目标面板查看。新局第 12 天能力需 ≥6 且两次成长回声已回来；状态需精力、心情各 ≥4 且做过两次恢复；支援需两次支援行动、关系 ≥6、金钱 ≥2。旧存档沿用原局规则。
6. 第 4 天可拖动三个滑块，预测第 7 天的精力、心情、洞察变化，也可以「先玩下去，暂不预测」。当天行动后进入默认约 46 秒的未来站演出；可以静静看完，或通过按钮、上滑推进。中断后恢复当前段落。做过预测时第 7 天查看预测与真实结果。
7. 第 12 天三维门依次响应，随后保留通过与未通过的条件。主动查看可能分支或时间地图，点击「再试一条时间线」后约 1.1 秒进入第二局。

## 三维与奖励

`HorizonWorld3D` 构建真实三维场景：现在与未来的同一角色、书桌与书本、手机、休息花园、朋友、长椅、城市、地平线光门和截止日三道门。角色有手臂与腿部关节、视线、眨眼、持物、走动和庆祝动作；未来自己走向个人记忆并触碰。相机、灯光、阴影、雾、边缘光与发光材质参与实际渲染。凝视未来降低环境音高频并放慢角色，回声从过去的日期飞向现在。图形与声音随仓库生成，无需下载付费素材。

每次行动获得 1 星尘；普通回声 3；连锁按实际路径层数；截止日获得 5＋每点亮一门 8。反馈包含三维飞散、飞入钱包的光点、分层音效与震动。右上角钱包可解锁黎明（25 星尘）与极光（60 星尘）配色，已解锁外观再次切换免费。星尘用于外观，预测成功仍主要扩大信息可见性。

内置 `HorizonSansSC.ttf` 基于 Noto Sans SC 制作，覆盖 GB2312 常用字符及当前游戏文本；来源、制作说明与 SIL OFL 授权随仓库保存。运行时按安全区域布局并请求竖屏。

## 因果与长期记录

- 六资源进入即时效果、延迟回声、条件投影、存档与三门结算。
- 每天可长按未来 0.65 秒凝视一次。第二局解锁 HORIZON II 的节点类型信息；第三次未来站解锁 HORIZON III 的两条条件未来。
- 预测接近实际结果累计 1、3、10 次，分别解锁方向、强度、二阶来源，只扩大信息可见性。
- 第三局起，透支可能让邀约缺席，高洞察带来「接住机会」，关系回应带来「并肩准备」。改写后的行动与新回声继续沿原来的因果路径成长。
- 支援与成长可以合流成为多来源事件；截止日三门连接对应的历史证据。CASCADE 根据实际因果节点计数并加速，七层起展示因果网络。存档保留多个父节点、实际资源变化和已兑现状态。
- 第三次未来站揭示未来的自己；玩家选择想保护的近期行为，后续凝视信息据此标注。
- 第二局逐步加入请教前辈、玩一局、夜里散步和四个日常情境；第一局继续保持简单。恢复选项始终可用。
- 时间地图可点开一天查看实际变化、来源和后续；展开可拖动的因果网络；按标题、行动或局数查找并筛选以前的人生。可以改标题，并改变多天的选择来探索一条支线，原档案和星尘不受影响。
- 七个不同的回访日逐步留下时间视野章节，不要求连续，也不因中断重置。第五章可观察截止日六资源的范围，第七章可查看 30 天的六资源展望。范围采样沿用真实规则并比较 24 组后续行动，不是回声随机兑现的概率；新局的 30 天展望使用长期项目、合作、分享成果、周末、重聚与庆祝等新行动，显示两条具体走法与三维未来自己；仍非完整的 30 天战役。
- 每隔 3～5 局触发低频视觉时刻：时间裂缝、另一个我、来自真实档案的记忆错位、尚未找到的因。多个真实回声同时抵达时可能形成回声风暴。结果等待确认，事件不改写资源。
- 已完成人生可预览并导出十秒竖屏 GIF（540×960，60 帧）。图像由实际 Unity Canvas 录制；10 秒动画先展示三个节点，再连成个人因果网络。Android 10+ 写入相册并打开系统分享选择器，由玩家选择去向；旧设备保留本地文件。分享文案仅在重演验证后声称某一天改变截止日结果。
- 旧三资源、旧因果图与旧卡牌版本存档会迁移并保留原局规则。

## 验证与构建

Unity Test Runner 的 EditMode 中运行全部测试：

- `GameSessionTests`：资源、回声、预测、存档迁移、三种选择事件、九层路径、三门及幻影重演。
- `PlayExperienceTests`：光圈椭圆边界、固定日期、可选预测、奖励存档、外观消费。
- `ExperienceContentTests`：旧局重演、多来源图、实际资源变化、新情境、历史门槛、多次选择分支、模拟隔离、30 天展望、不断签、档案检索和 GIF 压缩。
- `PlayableFlowTests`：进入真实 Play Mode，操作拖拽与按钮，验证结果停留及恢复、未来站完整播放与中断恢复、截止日、档案、分支、分享取消和重开；输出实际 Unity 渲染截图与 GIF。
- `tools/verify_timeline_exports.py`：Pillow 独立解码 Unity 导出的 GIF，核对压缩测试的每个像素、十秒时长、60 帧及画面变化。

Linux 无显示器时需 Xvfb 和图形设备，渲染测试不能使用 `-nographics`：

```bash
Unity -batchmode -force-glcore -projectPath . -runTests -testPlatform EditMode -testResults TestResults.xml
```

`.github/workflows/android-apk.yml` 在 PR 更新时先执行上述测试与截图，再通过 `Horizon.Editor.AndroidBuild.Build` 构建 IL2CPP Android APK，包含 ARMv7 与 ARM64，并校验两种架构的原生库。产物 `HORIZON-EditMode-Results`、`HORIZON-Unity-Portrait-Previews`、`HORIZON-Android-APK` 保留 14 天。试玩 APK 使用开发签名；正式发布需另配签名。

工作流使用仓库已有 Unity 授权密钥。首次配置时 Personal 需要 UNITY_LICENSE、UNITY_EMAIL、UNITY_PASSWORD；Pro 需要 UNITY_SERIAL、UNITY_EMAIL、UNITY_PASSWORD。

## 实际边界

三维模型、音效与动作仍是程序化原型，尚未达到成熟美术资产的品质。实际截图和规则测试不能证明游戏已足够有趣；触控成功率、反馈辨识、阅读时间、帧率、前一小时节奏和重玩意愿需要手机试玩。Android 原生分享入口需要设备验证。当前规则与 30 天展望还需更丰富内容和平衡，未来站的情感效果也需玩家评估。详见 [0–35 节逐项验收](docs/V03_ACCEPTANCE.md) 与 [体验验收清单](docs/PLAYABILITY_GAPS.md)。

## v0.3 本轮理念修正

- 新牌池从第三局加入天气与邀约，真实存档固定事件种子；概率说明环境的不确定性，已埋回声仍按时抵达。旧人生保留旧规则。
- Horizon II 限定一个类型，FOCUS 分页保留所有待回声；预测的“为什么”逐项显示三天真实变化与合计，预测不奖励货币。
- 成长投放安静、回声兑现强化；娱乐可留下正面余温，负面回声有疲惫回应。十二天星图和历史力量依次参与截止日。
- 回访章节可自愿选牌练习；跨局回声档案、三十天具体走法和记忆后来揭因可实际进入，观察不改写游戏。
- 自动化仍不能证明好玩或正式美术品质。逐项完成范围与调整理由见验收文档。
